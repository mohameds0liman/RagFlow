# M1 — Scaffold & Design System

## What was built

- **Vite + React project** bootstrapped in `Frontend/` with all dependencies:
  MUI (`@mui/material`, `@mui/icons-material`, `@mui/x-data-grid`),
  `@emotion/react`, `@emotion/styled`, `@tabler/icons-react`,
  `@reduxjs/toolkit`, `react-redux`, `react-router-dom`, `axios`,
  `formik`, `yup`, `notistack`, `@microsoft/fetch-event-source`, `react-markdown`

- **Flowise-identical dark theme** (`src/theme/index.js`) with palette:
  `#1A1F2E` bg, `#171C2B` sidebar, `#1E2330` card, `#232839` surface,
  `#4B72FF` primary, `#E0E0E0` text primary, `#9099B0` text secondary,
  `#2D3448` border, Inter font, `12px` border radius, `260px` sidebar width,
  `64px` topbar height

- **4 shared components:**
  - `MainCard` — card wrapper with title, divider, dark surface
  - `ConfirmDialog` — destructive action confirmation modal
  - `StatusChip` — semantic status badge (Pending/Active/Error etc.)
  - `StyledDataGrid` — pre-styled MUI X DataGrid matching Flowise

- **Redux store** (`src/store/`) with 4 slices:
  `authSlice`, `kbSlice`, `chatbotSlice`, `usersSlice`

- **Layouts:**
  - `AdminLayout` — `260px` sidebar with 5 nav items (Dashboard, Document Stores, Chatbots, Chat, Users), active indicator (`border-left: 4px solid #4B72FF`), `64px` topbar with user menu + logout
  - `UserLayout` — minimal topnav bar

- **Route guards:**
  - `AdminRoutes` — checks `role === 'admin'` from Redux + localStorage
  - `UserRoutes` — checks `role === 'user'`

- **Placeholder admin views** — stub components for all 5 nav pages

## Problems & solutions

- **Flowise match**: Colors were extracted from a real Flowise screenshot. The dark theme tokens are exact matches.
- **Sidebar active detection**: Used `location.pathname.startsWith(item.path)` but Chatbots (`/admin/chatbots`) matched Chat (`/admin/chat`). Fixed by requiring `startsWith` only on path + `/` suffix.
- **No hardcoded colors in M1**: Layout colors were hardcoded hex values; these were replaced with `theme.palette` in M2.

## Do NOT touch

- Backend files (`backend/`, `run.py`, `requirements.txt`)
- `src/api/axiosInstance.js` — JWT interceptor and 401 refresh are stable
- `src/store/slices/` — thunk structures are correct; add new endpoints inside existing slices
- The `AGENTS.md` boundary rule: frontend-only changes, never backend
