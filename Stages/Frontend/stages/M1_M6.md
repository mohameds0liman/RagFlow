## M5 — Chat System

**Built**: chatApi — 12 functions (Admin: create/list/delete sessions, list messages, send. User: list chatbots, create/list/delete sessions, list messages, send). ChatWindow — pure presentational, user right blue, AI left dark+Robot+react-markdown, auto-scroll, Thinking indicator, multiline Enter-to-send. UserChat — 2-panel, `GET /user/chatbots`, 429 rate-limit Alert banner, "No chatbots assigned" empty state. ChatbotSettingsDialog — added `castValue(value, type)` for numeric type conversion (`NUMERIC_TYPES = ['float', 'integer', 'number']`).
**Problems**: `temperature` pipeline error had **2 causes**: (a) type mismatch — TextField sends `"0.7"` string but Ollama expects float, fixed by `castValue()` using `parseFloat()`; (b) **missing key** — `typedConfig` builder used `if (field.name in form.llm_config)` which excluded untouched fields, so `temperature` was omitted from `build_config` entirely → `config["temperature"]` KeyError. Fixed by fallback to `field.default`:
```js
const raw = form.llm_config[field.name];
const value = (raw !== undefined && raw !== '') ? raw : field.default;
if (value !== undefined && value !== null)
  typedConfig[field.name] = castValue(value, field.type);
```
Applied in both ChatbotSettingsDialog and AdminChat. Trailing space in ChatOllama was a **false alarm** — file is correct, space is between `"` and `,` (formatting only). Live preview moved from dialog to sidebar panel. Session auto-creation on chatbot select.

**Other AdminChat fixes**: `selectedChatbot` now updates after settings save (captures thunk result). `store_id` added to update payload. `fetchKnowledgeBases()` dispatched in useEffect so KB dropdown populates on direct nav to `/admin/chat`. `.env` `VITE_API_URL=http://127.0.0.1:8000`.

## CROSS-CUTTING RULES

- **API**: Always import `api` from `axiosInstance.js`. JWTs auto-attached + auto-refresh on 401. File uploads use FormData. Errors from `err.response?.data?.detail`.
- **`listComponents(category)` returns OBJECT**: Convert via `Object.entries(data || {}).map(([name, inputs]) => ({ name, inputs }))`.
- **`Body()` endpoints expect raw values**: `triggerUpsert` sends `JSON.stringify(docId)` — do NOT wrap. Check 422 `"loc":["body"]` for diagnosis.
- **CSS grid**: `display: 'grid', gridTemplateColumns: 'repeat(3, 1fr)', gap: 3`. Cards `aspectRatio: '5/2'`. No MUI Grid.
- **StatusChip**: Every status variant (lowercase AND title-case) must be in map. Unknown → neutral gray.
- **Theme**: `theme/index.js` tokens are source of truth. No inline overrides. Reactive via `useMemo` in App.jsx.
- **Form fields**: `placeholder={String(field.default)}`, no helperText/required. LLM defaults use `?? ''` not `|| ''`.
- **Chatbot payload**: `{ name, description, store_id, llm_config: { name, build_config }, chain_config: { chain_type }, memory_config: { memory_type }, prompt_config: { template } }`. `build_config` values must be typed correctly.
- **typedConfig fallback**: Keep `(raw !== undefined && raw !== '') ? raw : field.default` pattern in both ChatbotSettingsDialog and AdminChat. Breaking it = temperature-style crash for any optional schema field.
- **ChatWindow**: Pure presentational. No API calls.
- **Upsert button**: Lives on doc card in DocumentStoreDetail, NOT in ChunksViewDialog.
- **Auth**: Response `{ access_token, user: { role, ... } }`. Read `data.user.role || data.role`. Refresh via HTTP-only cookie + `withCredentials: true`. Logout/401: clear storage+Redux → `/login`.

## BACKEND DEPENDENCIES (frontend cannot fix)

1. **`chunks_count` per doc**: Backend `admin.py:449` must add `extras=loader_counts(d.id, db)`. Without it, `doc.chunks_count ?? 0` shows 0.
2. **`POST /upsert` body format**: Uses `doc_id: str = Body()` without `embed=True`. If backend adds `embed=True`, frontend can switch to `{ doc_id: docId }`.
3. **Category names**: Frontend hardcodes `['embedder', 'vector_store', 'record_manager', 'loader', 'chunker', 'chat_model']`. Renames break the UI.
4. **Chatbot endpoints**: `POST` returns `{ status: "created", chatbot }`. `GET` returns `{ status, count, chatbots: [...] }`.
5. **UpdateChatbotRequest missing `store_id`**: Backend schema has no `store_id` field. Frontend sends it but backend silently ignores.
6. **`chain_config`**: Backend stores it but only `chain_type` is meaningfully used.
