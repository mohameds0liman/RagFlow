## overview

add prompt_config + chain_config support to the chat pipeline in factory.py

the ConversationalRetrievalChain.from_llm() passes combine_docs_chain_kwargs to load_qa_chain() which dispatches to chain-type-specific builders (_load_stuff_chain, _load_map_reduce_chain, etc.)

add different chain types and Admin can set the top k and last n pair messages of the chat history
## errors faced

each chain type has different kwarg names:

- **stuff**: needs `prompt` + `document_variable_name="context"` (default is "context" but must match {context} in the template)
- **refine**: needs `question_prompt` + `refine_prompt` + `document_variable_name="context"` (not "context_str")
- **map_reduce**: needs `question_prompt` (not "map_prompt") + `combine_prompt` + `combine_document_variable_name="context"` (combine step uses "summaries" by default but our prompt has {context})
- **map_rerank**: needs `prompt` + `document_variable_name` + the prompt must have a RegexParser on it (MapRerankDocumentsChain validates llm_chain.prompt.output_parser is a RegexParser), and the template must instruct the model to output a score format like `\nScore: <number>`



for now all chain types work except map_rerank it does not give an error but it does not also give answers will be fixed later
